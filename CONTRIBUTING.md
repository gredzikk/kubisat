# Contributing to Kubisat

We welcome contributions to the Kubisat project! Whether it's reporting a bug, suggesting a new feature, or submitting code changes, your help is appreciated.

## Getting Started

1.  **Fork & Clone:** Fork the repository and clone it to your local machine.
2.  **Set up Environment:** Follow the build instructions in the [README.md](README.md) to set up your development environment and ensure you can build the project successfully.
3.  **Create a Branch:** Create a new branch for your changes: `git checkout -b feature/your-feature-name`.

## Coding Style

*   Please follow the existing code style.
*   Document all public functions, classes, and variables using Doxygen-style comments.
*   Ensure your code is well-commented to explain complex logic.

## Submitting Pull Requests

1.  Commit your changes with a clear and descriptive commit message.
2.  Push your branch to your fork.
3.  Open a pull request against the `main` branch of the original repository.
4.  In the pull request description, explain the changes you have made and reference any related issues.

## Reporting Bugs

If you find a bug, please open an issue on GitHub. Provide as much detail as possible, including:
*   Steps to reproduce the bug.
*   Expected behavior.
*   Actual behavior.
*   Your hardware and software setup.
